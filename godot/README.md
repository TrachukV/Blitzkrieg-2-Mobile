# Godot presentation spike

This project is a renderer/input experiment, not a second implementation of
the game simulation. The legacy C++ runtime remains authoritative and publishes
versioned terrain, static-world, and entity snapshots through
`bk2_presentation_api.h`.

The Android runtime writes the real current snapshot to:

`<app no-backup dir>/presentation_snapshot.json`

Copy that file to `godot/data/presentation_snapshot.json` to render an actual
mission. The checked-in JSON is a transport fixture generated by the same C++
snapshot implementation; it deliberately does not claim to be decoded game
content.

## Local smoke test

```sh
cmake -S godot/native -B /tmp/bk2-godot-fixture
cmake --build /tmp/bk2-godot-fixture
ctest --test-dir /tmp/bk2-godot-fixture --output-on-failure
/tmp/bk2-godot-fixture/bk2_snapshot_fixture \
  godot/data/presentation_snapshot.json
godot --headless --path godot --quit-after 2
```

Success is reported as `BK2_GODOT_BRIDGE_OK`.
